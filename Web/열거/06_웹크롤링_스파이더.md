# 06_웹크롤링_스파이더

# 웹 크롤링 / 스파이더

시작 페이지에서 링크를 따라가며 사이트 전체를 자동으로 긁는다. 수동 클릭으로 찾을 정보(이메일, 숨은 링크, 서브도메인, JS, 주석)를 한 번에 모은다. 능동 정찰이라 요청이 많이 나가니, 권한 범위 안에서만 돌린다.

---

## 1. 크롤러가 모으는 것

- 이메일 - 사용자명 규칙, 피싱 대상
- 링크 / 서브도메인 - 숨은 페이지, 다른 서버 발견
- 외부 파일 - PDF, 문서 (메타데이터/내용에 민감정보)
- JS 파일 - API 엔드포인트, 하드코딩된 키 (분석은 07 참고)
- HTML 주석 - 개발자가 남긴 경로, 크리덴셜, TODO

## 2. ReconSpider (scrapy 기반)

HTB 모듈 정찰용 커스텀 스파이더. 결과를 results.json 으로 종류별 정리.

```bash
# scrapy 설치 (Kali 는 externally-managed 라 apt 또는 --break-system-packages)
sudo apt install python3-scrapy -y
#   또는: pip3 install scrapy --break-system-packages

# 실행
python3 ReconSpider.py http://<domain>
```

결과 파싱 (results.json):

```bash
# 키워드로 찾기 (예: 보고서 저장 위치)
grep -i "report" results.json

# 종류별로 보기
cat results.json | python3 -m json.tool | less
jq '.emails[]'  results.json      # 이메일만
jq '.links[]'   results.json | sort -u    # 링크/서브도메인
jq '.comments[]' results.json     # HTML 주석
```

## 3. katana (ProjectDiscovery, 빠름)

```bash
# 기본 크롤링
katana -u http://<IP>/ -d 3 -o katana.txt

# JS 포함 전체 URL 수집 (-jc: js 크롤링, -kf: known files robots/sitemap)
katana -u http://<IP>/ -jc -kf all -ef woff,css,png,svg,jpg,woff2,jpeg,gif -o katana.txt

# 헤드리스(동적 렌더링)로 JS 로 생성되는 링크까지
katana -u http://<IP>/ -headless -o katana-headless.txt
```

## 4. gospider

```bash
gospider -s http://<IP>/ -d 2 -c 10 --sitemap --robots -o gospider-out
#   -s 시작 URL, -d 깊이, -c 동시 요청, --sitemap/--robots 포함

# 결과에서 JS 만
grep -Eo "https?://[^\"']+\.js" gospider-out/* | sort -u
```

## 5. hakrawler (가볍고 빠름)

```bash
echo http://<IP>/ | hakrawler -d 2
echo http://<IP>/ | hakrawler -d 3 -subs    # 서브도메인 포함
```

## 6. Burp / ZAP Spider (GUI, 인증 세션 유지)

- Burp Suite - 로그인 세션을 유지한 채 크롤링. Target 탭에서 사이트맵 자동 구성. 인증 후 영역 정찰에 강함
- OWASP ZAP - 무료. Spider 기능으로 크롤링 + 자동 취약점 스캔 병행

로그인이 필요한 영역은 CLI 크롤러보다 세션을 쥔 Burp/ZAP 가 유리하다.

## 결과 활용

- 이메일 → 사용자명 규칙 추출 → 로그인 브루트포스/스프레이 대상
- 서브도메인 → 04(vhost/서브도메인)와 교차, 새 타겟 추가
- 외부 파일(PDF 등) → exiftool 로 메타데이터, 내용에서 내부정보
- JS 파일 → 07(JS분석_API추출)에서 엔드포인트/키 추출
- 주석 → 숨은 경로, 테스트 크리덴셜
