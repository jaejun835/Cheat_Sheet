# 디렉터리 / 파일 탐색 (gobuster dir / feroxbuster / ffuf)

웹 서버에서 링크로 드러나지 않는 디렉터리와 파일을 wordlist 로 brute-force 한다. 관리자 패널, 백업 파일, 설정 파일, .git 노출이 여기서 걸린다. vhost/서브도메인은 04, 찾은 경로를 어떻게 공략하는지는 05 참고.

## 공통 옵션 (기본 세트)

아래 예시들은 이 플래그를 기본으로 깐다. 환경에 맞게 속도만 조절한다.

```bash
# 기본값
-t 10            # 스레드
--timeout 20s    # 응답 대기
-b 404,400       # 없음/잘못된 요청 제외
-o <out>.txt     # 결과 저장

# 속도 조절 프리셋 (환경별)
#   빠른 로컬랩   : -t 30 --timeout 10s
#   느린 VPN     : -t 5  --timeout 30s
#   매우 불안정   : -t 2  --timeout 45s --delay 200ms
```

## gobuster dir

```bash
# 기본
gobuster dir -u http://<IP>/ -w /usr/share/seclists/Discovery/Web-Content/common.txt -t 10 --timeout 20s -o gb-common.txt

# 워드리스트 단계 상향 (common 에서 안 나오면)
#   common.txt → raft-small-directories.txt → raft-medium-directories.txt → directory-list-2.3-medium.txt
```

### 필터링

```bash
# 응답 크기로 노이즈 제거 (예: 모든 403 이 Size 162 로 뜰 때)
gobuster dir -u http://<IP>/ -w common.txt --exclude-length 162 -o gb-filter.txt

# 특정 상태코드만 보기
gobuster dir -u http://<IP>/ -w common.txt -s 200,301,302,401,403 -o gb-status.txt
```

### 확장자 탐색

```bash
# 스택에 맞춰 확장자 지정
gobuster dir -u http://<IP>/ -w common.txt -x php,txt,bak,old,zip -o gb-ext.txt
#   PHP  : php,txt,bak,old,zip
#   IIS  : asp,aspx,config,bak
#   Java : jsp,txt,bak
```

### 발견 경로 집중 / HTTPS / 인증

```bash
# 찾은 디렉터리 하위 재탐색 (gobuster 는 비재귀라 수동으로)
gobuster dir -u http://<IP>/admin/ -w common.txt -o gb-admin.txt

# HTTPS + 인증서 무시
gobuster dir -u https://<IP>/ -w common.txt -k -o gb-https.txt

# 쿠키 / 헤더 / Basic 인증
gobuster dir -u http://<IP>/ -w common.txt -c "PHPSESSID=<val>" -o gb-cookie.txt
gobuster dir -u http://<IP>/ -w common.txt -H "Authorization: Bearer <TOKEN>" -o gb-bearer.txt
gobuster dir -u http://<IP>/ -w common.txt -U <user> -P <pass> -o gb-basic.txt

# Burp 경유 (-t 낮춰서)
gobuster dir -u http://<IP>/ -w common.txt --proxy http://127.0.0.1:8080 -t 5 -o gb-burp.txt
```

## feroxbuster (자동 재귀 - 추천)

gobuster 와 달리 발견한 디렉터리 하위를 자동으로 파고든다. 1차 정찰에 강하다.

```bash
# 기본 디렉터리 탐색 (재귀 끄고 표면만 먼저: -n)
feroxbuster -u http://<IP>/ -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -t 30 -n -C 404,400 -o fx-dirs.txt

# 자동 재귀 + 확장자 (깊이 제한 -d)
feroxbuster -u http://<IP>/ -w raft-medium-directories.txt -x php,txt,bak -t 30 -d 3 -C 404,400 -o fx-rec.txt

# 응답 크기 필터
feroxbuster -u http://<IP>/ -w <wordlist> --filter-status 404 --filter-size 9265

# 쿠키 / 헤더
feroxbuster -u http://<IP>/ -w <wordlist> -H "Cookie: session=<val>" -H "Authorization: Bearer <TOKEN>"

# 중단된 스캔 재개
feroxbuster --resume-from fx-dirs.txt
```

## ffuf (가장 유연)

헤더, POST, JSON 까지 가장 자유롭게 퍼징한다. 필터는 수동 설정이 기본이다.

```bash
# 디렉터리
ffuf -u http://<IP>/FUZZ -w common.txt -mc 200,204,301,302,401,403

# 응답 크기로 노이즈 제거 (먼저 가짜 응답 크기 파악 후)
ffuf -u http://<IP>/FUZZ -w common.txt -fs <size>

# 확장자 위치 퍼징
ffuf -u http://<IP>/indexFUZZ -w /usr/share/seclists/Discovery/Web-Content/web-extensions.txt

# 파라미터 이름 / 값
ffuf -u "http://<IP>/page.php?FUZZ=test" -w burp-parameter-names.txt -fc 404
ffuf -u "http://<IP>/page.php?id=FUZZ" -w <wordlist> -mc 200 -fs <size>

# 결과 저장
ffuf -u http://<IP>/FUZZ -w <wordlist> -o ffuf.json -of json
```

(로그인 폼 brute-force, JSON POST 퍼징은 Hydra/로그인 공격 쪽 참고)

## 스캔 전후 보조 (curl)

```bash
# 응답 헤더 / 리다이렉트
curl -i http://<IP>/
curl -iL http://<IP>/admin

# 가짜 응답(없는 경로) 크기 미리 확인 → --exclude-length / -fs 값 잡기
curl -i http://<IP>/doesnotexist123

# HTML 에서 경로 추출
curl -s http://<IP>/ | grep -Eo 'src="[^"]+|href="[^"]+' | sort -u
```
