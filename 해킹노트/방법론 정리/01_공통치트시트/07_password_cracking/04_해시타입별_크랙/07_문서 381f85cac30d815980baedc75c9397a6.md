# 07_문서

# 해시 타입별 크랙 — 문서 (PDF / Office)

---

## PDF

```
방법: pdf2john으로 해시 추출 → john 또는 hashcat
버전별로 암호화 방식이 다름 → 해시 prefix로 구분
```

```bash
# 해시 추출
pdf2john document.pdf > pdf.hash

# john으로 크랙
john --wordlist=rockyou.txt pdf.hash
john --format=pdf --wordlist=rockyou.txt pdf.hash
john --show pdf.hash

# hashcat (파일명 부분 제거)
pdf2john document.pdf | cut -d: -f2 > pdf_only.hash

# 버전별 모드
hashcat -m 10400 pdf_only.hash rockyou.txt   # PDF 1.1–1.3 (Acrobat 2~4)
hashcat -m 10500 pdf_only.hash rockyou.txt   # PDF 1.4–1.6 RC4 128-bit (Acrobat 5~8, 가장 흔함)
hashcat -m 10600 pdf_only.hash rockyou.txt   # PDF 1.7 Level 3 (Acrobat 9)
hashcat -m 10700 pdf_only.hash rockyou.txt   # PDF 1.7 Level 8 AES-256 (Acrobat 10+)

# 버전 모를 때 → john 자동 감지가 더 편함
hashcat -m 10500 pdf_only.hash --show
```

## MS Office (Word / Excel / PowerPoint / OneNote)

```
지원 버전: Office 97 / 2000 / XP / 2003 / 2007 / 2010 / 2013
           Office 2016/2019는 2013 형식으로 저장된 경우에만 가능
지원 파일: .doc .docx .xls .xlsx .ppt .pptx .one .mpp .mdb .pst 등
방법: office2john으로 해시 추출 → john 또는 hashcat
버전별 모드가 다름 → 해시 내 $office$*연도* 부분으로 구분
```

```bash
# 해시 추출
office2john document.docx > office.hash
office2john spreadsheet.xlsx > office.hash
office2john presentation.pptx > office.hash

# 해시 내용 확인 → 버전 파악
cat office.hash
# 예: $office$*2013*100000*256*16*...  → 2013 형식 (mode 9600)
# 예: $office$*2010*100000*128*16*...  → 2010 형식 (mode 9500)
# 예: $office$*2007*50000*128*16*...   → 2007 형식 (mode 9400)

# john으로 크랙 (자동 감지)
john --wordlist=rockyou.txt office.hash
john --show office.hash

# hashcat (파일명 부분 제거 필요)
office2john document.docx | cut -d: -f2 > office_only.hash

# 버전별 모드
hashcat -m 9700 office_only.hash rockyou.txt    # Office <= 2003 (MD5+RC4) — 빠름
hashcat -m 9800 office_only.hash rockyou.txt    # Office <= 2003 (SHA1+RC4)
hashcat -m 9400 office_only.hash rockyou.txt    # Office 2007
hashcat -m 9500 office_only.hash rockyou.txt    # Office 2010
hashcat -m 9600 office_only.hash rockyou.txt    # Office 2013 / 2016 / 2019 — 느림

# 룰 추가 (2007 이하는 빠르니까 룰도 시도)
hashcat -m 9400 office_only.hash rockyou.txt -r /usr/share/hashcat/rules/best64.rule

hashcat -m 9600 office_only.hash --show
```
