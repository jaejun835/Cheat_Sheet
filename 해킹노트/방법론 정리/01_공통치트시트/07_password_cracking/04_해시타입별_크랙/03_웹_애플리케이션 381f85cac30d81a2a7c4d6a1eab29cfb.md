## MD5 (mode 0)

```
형식: 32자 hex
예시: 5f4dcc3b5aa765d61d8327deb882cf99 ("password")
특징: 매우 빠름 (GPU로 수백 GH/s), 단순 MD5는 솔트 없어서 취약
```

```bash
hashcat -m 0 hash.txt rockyou.txt
hashcat -m 0 hash.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule
john --format=raw-md5 --wordlist=rockyou.txt hash.txt
```

## bcrypt $2y$ / $2a$ / $2b$ (mode 3200)

```
형식: $2y$<cost>$<22자 솔트><31자 해시>
예시: $2y$10$...
특징: 의도적으로 느린 해시. cost factor(10)에 따라 속도가 극적으로 달라짐
      GPU로도 초당 수십~수천 개 수준 → 짧은 리스트 + 룰이 현실적
      cost 10 기준: 약 100~500 H/s (GPU), NTLM의 수천만분의 1 속도
```

```bash
hashcat -m 3200 hash.txt rockyou.txt

# bcrypt는 큰 리스트가 비현실적 → 상위 N개 + 룰 조합
hashcat -m 3200 hash.txt /usr/share/seclists/Passwords/Common-Credentials/10-million-password-list-top-10000.txt
hashcat -m 3200 hash.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule

john --format=bcrypt --wordlist=rockyou.txt hash.txt
```

## phpass $P$ / $H$ (mode 400)

```
형식: $P$<8자 솔트><22자 해시> 또는 $H$...
적용: WordPress, phpBB, Drupal 7 이전
특징: bcrypt보다는 빠르지만 MD5보다는 느림
```

```bash
hashcat -m 400 hash.txt rockyou.txt
hashcat -m 400 hash.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule
john --format=phpass --wordlist=rockyou.txt hash.txt
```

## SHA512crypt $6$ (mode 1800) / SHA256crypt $5$ (mode 7400)

```
형식: $6$<솔트>$<해시> (sha512crypt)
     $5$<솔트>$<해시> (sha256crypt)
적용: 리눅스 /etc/shadow (현대), 일부 웹 앱
특징: 반복 연산으로 느림 (기본 5000 라운드)
```

```bash
# SHA512crypt
hashcat -m 1800 hash.txt rockyou.txt
john --format=sha512crypt --wordlist=rockyou.txt hash.txt

# SHA256crypt
hashcat -m 7400 hash.txt rockyou.txt
john --format=sha256crypt --wordlist=rockyou.txt hash.txt
```

## MD5crypt $1$ (mode 500) / Apache MD5 $apr1$ (mode 1600)

```
형식: $1$<솔트>$<해시>    (MD5crypt — 리눅스 구버전 /etc/shadow)
     $apr1$<솔트>$<해시> (Apache MD5 — .htpasswd)
```

```bash
# MD5crypt $1$
hashcat -m 500 hash.txt rockyou.txt
john --format=md5crypt --wordlist=rockyou.txt hash.txt

# Apache MD5 $apr1$
hashcat -m 1600 hash.txt rockyou.txt
john --format=md5crypt-long --wordlist=rockyou.txt hash.txt
```
