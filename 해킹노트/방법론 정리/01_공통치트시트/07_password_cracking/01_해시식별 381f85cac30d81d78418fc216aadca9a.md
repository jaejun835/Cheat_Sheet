# 해시 식별

---

## 개념

해시 타입을 모르면 어떤 모드로 크래킹할지 알 수 없다. 자동 식별 툴과 눈으로 구분하는 패턴을 같이 써야 정확도가 높다. 툴이 여러 후보를 제시할 수 있으므로 패턴과 대조해서 최종 확인한다.

---

## 툴

```bash
# hashid — 가장 많이 씀
hashid '$2y$10$abc...'

# hashcat 모드 번호도 같이 출력
hashid -m '$2y$10$abc...'
hashid -m -j '$2y$10$abc...'   # john 포맷도 출력

# 파일 전체 분석
hashid -m hashes.txt

# hash-identifier (대화형)
hash-identifier
# → 프롬프트에 해시 붙여넣기

# name-that-hash — 가장 정확, 가장 많은 후보 제시
pip install name-that-hash
nth --text '$2y$10$abc...'
nth --file hashes.txt
nth --text '$2y$10$abc...' --no-banner    # 배너 없이

# hashcat 지원 해시 목록 + 예시 확인
hashcat --example-hashes | less
hashcat --example-hashes 2>&1 | grep "1000"
hashcat --help | grep -i bcrypt
```

## 눈으로 구분하는 패턴

```
# 길이 / hex 기반
32자 hex          → MD5           (mode 0)
40자 hex          → SHA1          (mode 100)
64자 hex          → SHA256        (mode 1400)
128자 hex         → SHA512        (mode 1700)
16자 hex          → MD5 (절반)    (mode 5100)

# prefix 기반
$1$...            → MD5crypt      (mode 500)    — 리눅스 구버전
$2y$... / $2a$... / $2b$...  → bcrypt (mode 3200)
$5$...            → SHA256crypt   (mode 7400)   — 리눅스
$6$...            → SHA512crypt   (mode 1800)   — 리눅스 현대
$P$ / $H$         → phpass        (mode 400)    — WordPress/phpBB
$apr1$...         → Apache MD5    (mode 1600)   — .htpasswd
$8$...            → Cisco Type 8  (mode 9200)
$9$...            → Cisco Type 9  (mode 9300)
$office$*2007*... → MS Office 2007 (mode 9400)
$office$*2010*... → MS Office 2010 (mode 9500)
$office$*2013*... → MS Office 2013 (mode 9600)
$keepass$*2*...   → KeePass 2.x   (mode 13400)
PWS3...           → Password Safe v3 (mode 5200)
$y$...            → yescrypt      (mode 25600)  — 현대 리눅스

# AD / Kerberos
32자 hex                           → NTLM        (mode 1000)
aad3b435b51404eeaad3b435b51404ee  → LM 더미값 (비어있음)
유저::도메인:챌린지:HMAC:blob      → NetNTLMv2   (mode 5600)
유저::도메인:LM:NTLM:챌린지       → NetNTLMv1   (mode 5500)
$krb5tgs$23$*...                   → Kerberoast RC4    (mode 13100)
$krb5tgs$17$*...                   → Kerberoast AES128 (mode 19600)
$krb5tgs$18$*...                   → Kerberoast AES256 (mode 19700)
$krb5asrep$23$...                  → AS-REP RC4        (mode 18200)
```
