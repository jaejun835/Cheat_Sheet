## 커스텀 워드리스트 생성

### cewl — 웹사이트 spider 기반

타겟 사이트에서 실제로 사용하는 단어를 추출. 사원명, 제품명, 회사 용어 등이 포함될 수 있어 효과적.

```bash
# 기본 (깊이 2, 최소 5글자)
cewl -d 2 -m 5 -w wordlist.txt http://target.com

# 깊이 늘리고 숫자 포함
cewl -d 3 -m 5 --with-numbers -w wordlist.txt http://target.com

# 이메일 주소도 수집
cewl -d 2 -m 5 -e --email_file emails.txt -w wordlist.txt http://target.com

# 인증 필요 페이지
cewl -d 2 -m 5 -w wordlist.txt \
  --auth_type basic --auth_user admin --auth_pass password \
  http://target.com/admin

# User-Agent 지정
cewl -d 2 -m 5 --ua "Mozilla/5.0" -w wordlist.txt http://target.com
```

### crunch — 패턴 기반 생성

```bash
# 형식: crunch <최소길이> <최대길이> [문자셋] [옵션]

# 8자리 모든 소문자
crunch 8 8 abcdefghijklmnopqrstuvwxyz -o wordlist.txt

# 특수문자 포함
crunch 8 12 abcdefghijklmnopqrstuvwxyz0123456789!@#$ -o wordlist.txt

# 패턴 지정
# @ = 소문자, , = 대문자, % = 숫자, ^ = 특수문자
crunch 8 8 -t ,@@@@%%%  -o wordlist.txt    # 대문자1 소문자4 숫자3
crunch 8 8 -t @@@@%%%%  -o wordlist.txt    # 소문자4 숫자4
crunch 11 11 -t @@@@@@@0728               # 끝 4자리 고정 (생일)

# 특정 단어 포함
crunch 1 1 -p apple banana cherry          # 순열 생성
```

### john 룰 기반 변형

기존 워드리스트를 패턴 변형 (대소문자, 숫자 추가, 특수문자 등)

```bash
# 기본 룰 적용
john --wordlist=wordlist.txt --rules --stdout > mutated.txt

# 특정 룰셋
john --wordlist=wordlist.txt --rules=best64 --stdout > mutated.txt
john --wordlist=wordlist.txt --rules=KoreLogic --stdout > mutated.txt
john --wordlist=wordlist.txt --rules=jumbo --stdout > mutated.txt

# hashcat 룰
hashcat --stdout -r /usr/share/hashcat/rules/best64.rule wordlist.txt > mutated.txt
hashcat --stdout -r /usr/share/hashcat/rules/rockyou-30000.rule wordlist.txt > mutated.txt

# 여러 룰 동시 적용
hashcat --stdout \
  -r /usr/share/hashcat/rules/best64.rule \
  -r /usr/share/hashcat/rules/toggles1.rule \
  wordlist.txt > combined_mutated.txt
```

## 해시 크래킹용 워드리스트

```bash
# hashcat 기본
hashcat -m 0 hashes.txt /usr/share/wordlists/rockyou.txt           # MD5
hashcat -m 100 hashes.txt /usr/share/wordlists/rockyou.txt         # SHA1
hashcat -m 1000 hashes.txt /usr/share/wordlists/rockyou.txt        # NTLM
hashcat -m 1800 hashes.txt /usr/share/wordlists/rockyou.txt        # sha512crypt
hashcat -m 18200 hashes.txt /usr/share/wordlists/rockyou.txt       # Kerberos AS-REP
hashcat -m 13100 hashes.txt /usr/share/wordlists/rockyou.txt       # Kerberos TGS

# 룰 적용
hashcat -m 1000 hashes.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule

# john
john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
john --format=NT hashes.txt --wordlist=rockyou.txt
```

## 팁

- OSCP 시험에서 `rockyou.txt`가 대부분 커버
- 패스워드 스프레이 전 락아웃 정책 반드시 확인
- cewl로 타겟 사이트 스파이더링한 단어가 가장 효과적
- 작은 리스트로 먼저 빠르게 시도 후 큰 리스트로 확장
- SecLists는 상황별로 잘 분류되어 있어 반드시 숙지
