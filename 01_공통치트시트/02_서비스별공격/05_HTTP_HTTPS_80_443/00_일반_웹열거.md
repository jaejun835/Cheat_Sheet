# 00_일반_웹열거

HTTP 서비스를 발견하면 아래 순서로 진행한다. 기술 스택과 서버 정보를 파악하고, 디렉토리 및 숨겨진 경로를 열거한 뒤 취약점 탐색으로 이어간다.

---

## 1. 기본 확인

```bash
# 배너 확인
curl -I http://<IP>
curl -I http://<IP> -k    # HTTPS 인증서 무시
nc -nv <IP> 80            # 원시 연결

# 웹 기술 스택 식별
# 서버 시그니처, CMS, 프레임워크, 언어, WAF 등 자동 탐지
whatweb http://<IP>
whatweb http://<IP> -v    # 상세 출력

# WAF 유무 확인
wafw00f http://<IP>

# Nikto 자동 취약점 스캐너
# 설정 오류, 기본 파일, CVE 등 자동 탐지
nikto -h http://<IP>
nikto -h http://<IP> -p 8080    # 포트 지정
nikto -h http://<IP> -ssl       # HTTPS
```

---

## 2. 디렉토리 / 파일 열거

디렉토리와 파일 열거는 반드시 실행해야 한다. 눈에 보이지 않는 관리자 패널, 백업 파일, 설정 파일 등이 자주 발견된다.

```bash
# feroxbuster — 재귀적 + 빠름 (일반적으로 가장 많이 사용)
feroxbuster -u http://<IP> -w /usr/share/wordlists/dirb/common.txt
feroxbuster -u http://<IP> -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt
feroxbuster -u http://<IP> \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt \
  -x php,txt,html,bak,old,zip    # 확장자 필터

# gobuster
gobuster dir -u http://<IP> -w /usr/share/wordlists/dirb/common.txt
gobuster dir -u http://<IP> \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt \
  -x php,txt,html,bak -t 50

# dirsearch
dirsearch -u http://<IP> -x 404
dirsearch -u http://<IP> -e php,html,js,txt

# ffuf
ffuf -u http://<IP>/FUZZ -w /usr/share/wordlists/dirb/common.txt
ffuf -u http://<IP>/FUZZ \
  -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt \
  -fc 404
```

## 3. 가상 호스트 (vhost) 열거

동일 IP에 여러 도메인이 호스팅되는 경우 있음. Host 헤더를 바꿔서 확인한다.

```bash
# gobuster vhost
gobuster vhost -u http://<도메인> -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt

# ffuf
ffuf -u http://<IP> -H "Host: FUZZ.<도메인>" \
  -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt \
  -fc 302,404

# 발견한 vhost /etc/hosts에 등록
echo "<IP> sub.<도메인>" >> /etc/hosts
```

## 4. 소스 코드 / JavaScript 분석

```bash
# 페이지 소스에서 민감 정보 탐색
curl http://<IP>/ | grep -i "api\|endpoint\|secret\|key\|token\|password\|admin"

# JS 파일 다운로드 후 분석
curl http://<IP>/js/app.js | grep -i "api\|endpoint\|key\|token"

# 헤더 정보 확인 (X-Powered-By, Server, Cookie 등)
curl -vv http://<IP>/ 2>&1 | grep -i "< "

# robots.txt, sitemap.xml, 기타 일반 경로
curl http://<IP>/robots.txt
curl http://<IP>/sitemap.xml
curl http://<IP>/.well-known/
curl http://<IP>/crossdomain.xml
```

## 5. 기술 스택별 추가 열거

```bash
# PHP
curl http://<IP>/phpinfo.php
curl http://<IP>/info.php
feroxbuster -u http://<IP> -x php -w /usr/share/wordlists/dirb/common.txt

# WordPress
curl http://<IP>/wp-login.php
curl http://<IP>/wp-admin/
curl http://<IP>/xmlrpc.php
wpscan --url http://<IP>

# Drupal
curl http://<IP>/user/login
curl http://<IP>/CHANGELOG.txt    # 버전 확인
droopescan scan drupal -u http://<IP>

# Joomla
curl http://<IP>/administrator/
curl http://<IP>/README.txt
joomscan --url http://<IP>

# IIS (.aspx)
feroxbuster -u http://<IP> -x aspx,asp,config -w /usr/share/wordlists/dirb/common.txt

# Tomcat
curl http://<IP>:8080/manager/html
curl http://<IP>:8080/host-manager/html

# 백업 파일 탐색
feroxbuster -u http://<IP> -x bak,old,backup,orig,swp -w /usr/share/wordlists/dirb/common.txt
```

## 6. 기본 자격증명 및 파라미터 탐색

```bash
# 발견된 로그인 페이지에 기본 자격증명 시도
curl -u admin:admin http://<IP>/admin/
curl -u admin:password http://<IP>/admin/

# GET/POST 파라미터 fuzzing (ffuf)
ffuf -u "http://<IP>/login.php?FUZZ=test" \
  -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt

# 업로드 경로 확인
feroxbuster -u http://<IP>/upload/ -w /usr/share/wordlists/dirb/common.txt
```

## 팁

```
1. whatweb + nikto → 기술 스택 파악
2. feroxbuster + dirsearch → 디렉토리 열거 (복수 확장자)
3. robots.txt + JS 분석 → 숨겨진 엔드포인트 탐색
4. 기술 스택 확인 → CMS별 특화 열거
5. 발견한 곳마다 취약점 탐색 (LFI/업로드/SQLi/RCE 등)
```
