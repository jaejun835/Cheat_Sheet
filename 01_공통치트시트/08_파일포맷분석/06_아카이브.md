# 06_아카이브

# 파일 포맷 분석 — 아카이브 (ZIP / RAR / 7z)

---

## 개념

암호화된 아카이브 파일은 내부에 중요한 파일(문서, 인증서, 설정 파일 등)이 들어있는 경우가 많다. 아카이브를 발견하면 먼저 내용 목록을 확인하고, 암호화 여부와 방식을 파악한 뒤 해제를 시도한다. 패스워드 크래킹은 `07_password_cracking` 참조.

---

## ZIP

```bash
# 파일 타입 확인
file archive.zip

# 내용 목록 확인 (압축 해제 전)
unzip -l archive.zip

# 상세 정보 확인 (압축 방식, 암호화 여부, 파일 크기)
# Method: AE-x 또는 Encryp: yes 이면 암호화됨
zipinfo archive.zip
zipinfo -v archive.zip   # 더 상세한 정보

# 암호화 여부만 빠르게 확인
zipinfo archive.zip | grep -i "encrypt\|AE-"

# 일반 압축 해제
unzip archive.zip
unzip archive.zip -d output_dir/

# 패스워드 있을 때
unzip -P 'password' archive.zip

# 내용물에서 문자열 검색 (압축 해제 전)
zipgrep "password" archive.zip
zipgrep -i "pass\|user\|secret" archive.zip
```

## AES 암호화 ZIP (unzip 안 될 때)

`unzip`은 AES 암호화(압축 방식 99)를 지원하지 않는다. WinZip이나 Windows에서 AES 암호화로 생성한 ZIP 파일을 unzip으로 열면 아래 에러가 발생한다.

```
skipping: filename    unsupported compression method 99
```

```bash
# 7z 설치
sudo apt install p7zip-full

# 내용 목록 확인
7z l archive.zip

# AES 암호화 여부 확인
# Encrypted: + 이면 암호화됨 / Method에 AES 표시
7z l -slt archive.zip | grep -i "encrypted\|method"

# AES 암호화 ZIP 해제
# -p: 패스워드 (옵션 바로 뒤에 공백 없이 입력)
7z x -p'password' archive.zip

# 출력 디렉토리 지정
# -o: 출력 경로 (옵션 바로 뒤에 공백 없이 입력)
7z x -p'password' -o./output archive.zip

# 패스워드 없는 일반 해제
7z x archive.zip
```

## RAR

```bash
# 설치
sudo apt install unrar

# 내용 목록 확인
unrar l archive.rar

# 상세 정보 확인 (암호화 여부, 압축 방식)
unrar v archive.rar

# 압축 해제
unrar x archive.rar
unrar x archive.rar output_dir/

# 패스워드 있을 때
unrar x -p'password' archive.rar

# 7z로도 가능
7z l archive.rar
7z x archive.rar
7z x -p'password' archive.rar
```

## 7z

```bash
# 내용 목록 확인
7z l archive.7z

# 상세 정보 확인
7z l -slt archive.7z | grep -i "encrypted\|method\|path"

# 압축 해제
7z x archive.7z

# 패스워드 있을 때
7z x -p'password' archive.7z

# 출력 디렉토리 지정
7z x -p'password' -o./output archive.7z
```

## 압축 해제 후 탐색

```bash
# 압축 해제 후 내용 확인
ls -la output_dir/
find output_dir/ -type f | sort

# 파일 타입 일괄 확인
find output_dir/ -type f -exec file {} \;

# 자격증명 키워드 탐색
grep -r -i "pass\|pwd\|user\|secret\|token" output_dir/

# 설정 파일 탐색
find output_dir/ -name "*.conf" -o -name "*.cfg" -o -name "*.ini" -o -name "*.xml" -o -name "*.json" | xargs grep -l "pass\|user\|secret" 2>/dev/null
```
