# 포트 노킹(port knocking)

포트 노킹은 서버의 포트가 숨겨져 있을 경우 사용자가 정해진 순서대로 포트 노킹을 할 때 방화벽이 잠깐 특정 포트를 열어주는 방식이다

예를 들어 서버가 이렇게 보일 경우

```
22 open
80 filtered
1337 filtered
```

만약 아래와 같이 관리자가 정한 비밀 순서가 있다고 친다면

```
1 → 2 → 3
```

클라이언트가 이 순서대로 접속 시도했을 때 

```bash
nc -zv 192.168.122.227 1
nc -zv 192.168.122.227 2
nc -zv 192.168.122.227 3
```

서버 방화벽이 포트 노킹을 확인한 후 숨겨진 포트를 열어주게 된다

```
1337 open
```

그다음 다시 스캔하면 새 포트가 보이는 식이다

쉽게 말하면 포트 노킹 비밀 노크 순서를 맞히면 숨겨진 서비스가 열리는 방화벽 트릭이라고 생각하면 된다
