# 01_리눅스

# 해시 타입별 크랙 — 리눅스 (/etc/shadow)

---

## 개념

리눅스 패스워드 해시는 `/etc/shadow`에 저장된다. 형식은 `유저명:$알고리즘$솔트$해시:...` 이며 prefix로 알고리즘을 구분한다. 현대 리눅스(Ubuntu 20.04+, Debian 11+)는 SHA512crypt($6$)를 기본으로 사용한다.

크래킹하려면 `/etc/passwd`와 `/etc/shadow` 두 파일이 모두 필요하다. `unshadow`로 합친 뒤 john에 넘기거나, 해시 부분만 추출해서 hashcat에 넘긴다.

```
prefix 구분:
$1$  → MD5crypt     (구버전)
$2y$ → bcrypt       (일부 배포판)
$5$  → SHA256crypt
$6$  → SHA512crypt  (현대 기본)
$y$  → yescrypt     (최신 Ubuntu 22.04+)
```

---

## unshadow → john

```bash
# passwd + shadow 합치기
unshadow /etc/passwd /etc/shadow > shadow.hash

# 자동 감지로 크랙
john --wordlist=rockyou.txt shadow.hash

# 포맷 명시 (명시하는 게 더 빠름)
john --format=sha512crypt --wordlist=rockyou.txt shadow.hash   # $6$
john --format=sha256crypt --wordlist=rockyou.txt shadow.hash   # $5$
john --format=md5crypt --wordlist=rockyou.txt shadow.hash      # $1$
john --format=bcrypt --wordlist=rockyou.txt shadow.hash        # $2y$
john --format=yescrypt --wordlist=rockyou.txt shadow.hash      # $y$

# 룰 적용
john --format=sha512crypt --wordlist=rockyou.txt --rules shadow.hash

# 결과 확인
john --show shadow.hash
john --show --format=sha512crypt shadow.hash
```

## 해시만 추출 → hashcat

shadow 파일에서 해시 부분만 추출해서 hashcat에 넘긴다. 세 번째 필드(콜론 기준)가 해시다.

```bash
# 해시 부분만 추출
awk -F: '$2 ~ /^\$/ {print $2}' /etc/shadow > shadow_hashes.txt
# 또는
cut -d: -f2 /etc/shadow | grep '^\$' > shadow_hashes.txt

# hashcat으로 크랙
hashcat -m 1800 shadow_hashes.txt rockyou.txt                   # $6$ SHA512crypt
hashcat -m 7400 shadow_hashes.txt rockyou.txt                   # $5$ SHA256crypt
hashcat -m 500  shadow_hashes.txt rockyou.txt                   # $1$ MD5crypt
hashcat -m 3200 shadow_hashes.txt rockyou.txt                   # $2y$ bcrypt
hashcat -m 25600 shadow_hashes.txt rockyou.txt                  # $y$ yescrypt

# 룰 추가
hashcat -m 1800 shadow_hashes.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule

# 결과 확인
hashcat -m 1800 shadow_hashes.txt --show
```
