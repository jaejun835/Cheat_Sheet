## ZIP

```
방법: zip2john으로 해시 추출 → john 또는 hashcat
주의: zip2john 출력 형식이 john용이라 hashcat에 넣으려면 파일명 부분 제거 필요
      ZIP 암호화 방식에 따라 hashcat 모드가 다름 (WinZip AES vs PKZIP)
```

```bash
# 해시 추출
zip2john secret.zip > zip.hash

# john으로 크랙 (그대로 사용 가능)
john --wordlist=rockyou.txt zip.hash
john --format=zip --wordlist=rockyou.txt zip.hash
john --show zip.hash

# hashcat으로 크랙 (파일명:해시 에서 해시 부분만 추출)
zip2john secret.zip | cut -d: -f2 > zip_only.hash

# 암호화 방식별 모드
hashcat -m 13600 zip_only.hash rockyou.txt   # WinZip AES (가장 흔함)
hashcat -m 17200 zip_only.hash rockyou.txt   # PKZIP (압축)
hashcat -m 17210 zip_only.hash rockyou.txt   # PKZIP (비압축)
hashcat -m 17220 zip_only.hash rockyou.txt   # PKZIP (혼합)
# 모드 모를 때 → john이 자동 감지해서 편함

hashcat -m 13600 zip_only.hash --show
```

## RAR

```
방법: rar2john으로 해시 추출 → john 또는 hashcat
RAR3와 RAR5 버전에 따라 hashcat 모드가 다름
RAR5가 더 강한 암호화 (AES-256 + PBKDF2)
```

```bash
# 해시 추출
rar2john archive.rar > rar.hash

# john으로 크랙
john --wordlist=rockyou.txt rar.hash
john --format=rar --wordlist=rockyou.txt rar.hash
john --show rar.hash

# hashcat
rar2john archive.rar | cut -d: -f2 > rar_only.hash
hashcat -m 13000 rar_only.hash rockyou.txt   # RAR5
hashcat -m 23800 rar_only.hash rockyou.txt   # RAR3-hp

hashcat -m 13000 rar_only.hash --show
```

## 7-Zip

```
방법: 7z2john으로 해시 추출 → john 또는 hashcat
7z는 AES-256 암호화 + 강한 키 유도 → 느림
```

```bash
# 해시 추출
7z2john archive.7z > 7z.hash

# john으로 크랙
john --wordlist=rockyou.txt 7z.hash
john --format=7z --wordlist=rockyou.txt 7z.hash
john --show 7z.hash

# hashcat
7z2john archive.7z | cut -d: -f2 > 7z_only.hash
hashcat -m 11600 7z_only.hash rockyou.txt
hashcat -m 11600 7z_only.hash rockyou.txt -r /usr/share/hashcat/rules/best64.rule

hashcat -m 11600 7z_only.hash --show
```

## OpenSSL 암호화 GZIP / TAR

```
방법: file 로 실제 포맷 확인 → 워드리스트로 openssl 복호화를 직접 반복 시도
gzip, tar 는 자체 암호 기능이 없어서 openssl 이나 gpg 로 감싸서 암호화한다
해시 크랙은 오탐이 많아서, 복호화 후 압축 해제까지 성공하는 후보를 정답으로 본다
```

```bash
# 정체 확인 (확장자가 .gzip 이어도 실제론 openssl 로 감싼 경우)
file <파일>
# → openssl enc'd data with salted password

# 워드리스트로 복호화 시도, 성공하면 비밀번호 출력 후 멈춤
while read -r p; do
  openssl enc -aes-256-cbc -d -in <파일> -k "$p" 2>/dev/null | tar xz 2>/dev/null && { echo "[+] $p"; break; }
done < /usr/share/wordlists/rockyou.txt

# 압축 해제된 파일 확인
ls
```

주의: HTB 모듈의 `for i in $(cat rockyou.txt)` 방식은 공백 들어간 후보가 쪼개지고, 정답을 찾아도 끝까지 돈다. 위처럼 while read 에 break 를 거는 게 낫다.

주의 2: 정답 비밀번호인데도 안 풀리면 키 유도 옵션이 다른 것이다. OpenSSL 1.1.0 부터 기본 다이제스트가 md5 에서 sha256 으로 바뀌어서, 구버전으로 만든 파일이면 `-md md5` 를, `-pbkdf2` 로 만든 파일이면 `-pbkdf2` 를 붙여야 한다.
