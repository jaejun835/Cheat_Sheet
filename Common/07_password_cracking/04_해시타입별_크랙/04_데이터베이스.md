# 04_데이터베이스

# 해시 타입별 크랙 — 데이터베이스

---

## MySQL323 (mode 200)

```
형식: 16자 hex (짧음)
획득: MySQL 3.x 이하, OLD_PASSWORD() 함수
특징: 매우 취약한 알고리즘, 충돌 가능성 높음
```

```bash
hashcat -m 200 hash.txt rockyou.txt
john --format=mysql --wordlist=rockyou.txt hash.txt
```

---

## MySQL4.1 / MySQL5+ (mode 300)

```
형식: *로 시작하는 41자 (예: *4A7B5D...)
획득: MySQL user 테이블 (SELECT user, authentication_string FROM mysql.user)
특징: SHA1(SHA1(password)) 이중 해싱
```

```bash
# * 제거 후 사용하거나 그대로 사용
hashcat -m 300 hash.txt rockyou.txt
john --format=mysql-sha1 --wordlist=rockyou.txt hash.txt
```

---

## MSSQL

```
획득: xp_cmdshell, secretsdump, impacket-mssqlclient
버전별 형식이 다름 — 해시 prefix 또는 길이로 구분
```

```bash
# MSSQL 2000 (mode 131)
hashcat -m 131 hash.txt rockyou.txt

# MSSQL 2005 (mode 132)
hashcat -m 132 hash.txt rockyou.txt

# MSSQL 2012 / 2014 (mode 1731)
hashcat -m 1731 hash.txt rockyou.txt

john --format=mssql --wordlist=rockyou.txt hash.txt
john --format=mssql05 --wordlist=rockyou.txt hash.txt
john --format=mssql12 --wordlist=rockyou.txt hash.txt
```

---

## PostgreSQL (mode 12)

```
형식: md5<32자 hex>
획득: pg_shadow 테이블 (SELECT usename, passwd FROM pg_shadow)
```

```bash
hashcat -m 12 hash.txt rockyou.txt
john --format=postgres --wordlist=rockyou.txt hash.txt
```

## Oracle

```bash
# Oracle 11g (mode 112) — SHA1 기반
hashcat -m 112 hash.txt rockyou.txt

# Oracle 12c (mode 12300) — PBKDF2 기반, 느림
hashcat -m 12300 hash.txt rockyou.txt

john --format=oracle11 --wordlist=rockyou.txt hash.txt
```
